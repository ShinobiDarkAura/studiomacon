Forms

Every input treatment on the site — none of them share exactly the same rule weight, colour or placeholder tone. This page shows each one as it actually appears, plus the base .field rule that nobody uses unmodified.

Anatomy

Inputs are always underlined, never boxed — the site has no bordered text field anywhere. Every field's rule darkens to black on focus. Four different rule specs and three placeholder colours are in live use; see the inconsistency table below.

Responsive

The contact form's two-column .row collapses to one column implicitly at narrow widths where the form itself is centred and full-width; no explicit breakpoint changes field styling. Upload tiles stay a 4-across grid at every width.

Do / Don't

Do
  • Underline every field — never box one.
  • Darken the rule to black on focus.
  • Match the rule/placeholder pair already used on that page's form (see the inconsistency table) rather than inventing a new pairing.
Don't
  • Ship the raw default .field — every real page overrides it.
  • Add a border, background fill or radius to a text input.
  • Use a fourth placeholder colour; pick from #777 (legacy default), rgba(0,0,0,.35), or rgba(0,0,0,.22).
