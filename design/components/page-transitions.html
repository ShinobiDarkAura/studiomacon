Page Transitions

Every scroll-in, page-leave and hover motion on the site, gathered in one place with its exact timing. The site's rule of thumb: things drift up and settle into focus rather than snap, and every effect turns off completely under reduced motion.

Live catalogue

.dr-emerge — the standard scroll-in

block

Opacity 0 → 1, blur 16px → none, translateY(66px) scale(.985) → none. 1.1s, cubic-bezier(.16,1,.3,1). Used on nearly every scrolled-in block on the site (18 uses) — accordions, prose, gallery figures, footer items.

Wall variant — shop grid tiles

tile

No blur; translateY(90px) → none; opacity .7s ease, transform .9s cubic-bezier(.2,1.25,.35,1) — the slight overshoot reads as a tile dropping into place rather than emerging from focus.

Soft page fade (default page-to-page)

page content

Leaving: a white veil rises to full opacity over 300ms, cubic-bezier(.4,0,.6,1), then the browser navigates. Arriving: the new page starts under that same veil, which lifts over 450ms, cubic-bezier(.4,0,.2,1), once its first pictures are ready (never later than 900ms). This is the default for every ordinary link; it is skipped for the phone drawer, which handles its own dim, and for Back/Forward.

Page wipe (parked)

page content

A single opaque black panel drops from above to cover the page in 420ms (cubic-bezier(.5,0,.25,1)), the page is swapped while hidden, then the panel continues off the bottom to uncover the new page over 500ms with the same easing. It never reverses the way it came. Currently parked (ON = false in build_pdp.py/site.js) — reserved for the walk back from a single piece to the shop.

Product info drawer-in

info column

translateX(40%) opacity 0 → none/1, .55s cubic-bezier(.2,.8,.2,1). Plays once on arrival at a product page, ≥768px only, when motion is not reduced.

Thumb-in

Product thumbnail strip: opacity 0 + translateY(10px) → none, .7s --ease-emerge, staggered 70ms apart starting 350ms in.

Menu-in

ShopCustomAbout

Drawer links: opacity 0 + translateY(18px) → none, .55s cubic-bezier(.16,1,.3,1), 60ms apart, starting 220ms in. See Menu Drawer.

Tile hover zoom

Hover state, forced: — resting scale var(--z,1.12) (set per photo in the lab), hovered scale var(--z) * 1.02, over 1.2s cubic-bezier(.2,.7,.2,1). Used on every shop tile and related-piece frame.

Reduced motion

@media (prefers-reduced-motion: reduce) turns every one of these off: .dr-emerge loses its transition entirely (blocks simply appear seen), the menu sheet and page push lose their transitions and the rise-in animation is dropped, the scroll cue's dot animation stops, and the page wipe and fade veils return early without running. Nothing on the site animates when this is set.
