Phones

No phone-specific override in build_emails.py — the box has a fixed padding and sits inside the standard .pad 24px side gutter.

Do / Don't

Do
  • Reserve the yellow highlighter for the discount code, and only the code.
  • Keep the note above the code in grey uppercase, never black.
  • Keep the box border at .12 opacity — it should read as a light frame, not a heavy outline.
Don't
  • Never use the highlighter yellow anywhere else in an email — not on a headline, a button, or a price.
  • Don't round the highlighter's corners evenly; the uneven radius is what makes it read as marker ink.
  • Don't change the note copy without checking it still fits one line inside 34px padding.
