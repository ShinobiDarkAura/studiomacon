Studio Maçon · Product Tile

Product Tile

The one clipped 4:5 frame that carries a piece everywhere it appears — the shop wall, the phone grid, and Also Worth Keeping on a product page. Same frame, three ways of labelling it.

Anatomy

Every tile is a link (.piece or .rel-piece) wrapping a clipped .pic/.rel-frame photograph and a label. The still photograph and the in-hand .held photograph sit in the same frame; hovering cross-fades to the held shot and zooms the whole image a further 2%. Framing (--x/--y/--z) is set per piece in the lab, never guessed — the demo below uses centred defaults.

Live — desktop overlay (3 across)

Default shop-wall layout ≥768px. Name and price are white, rise over a bottom scrim on hover, above a still-to-held cross-fade and a 2% zoom.

Live — phones / labels-under (2 across)

Below 768px, and on desktop when the shop opts into body.labels-under: a rounded 6px frame with the name and price set underneath it, always visible (no scrim, no rising label).

On a touch device (hover:none) the held image never shows — the still is the only picture, labels stay put.

Live — Also Worth Keeping

The related-pieces card on a product page: a lighter cousin of the labels-under tile — the frame lifts -8px on hover instead of cross-fading, and the name runs larger (38px desktop, 22px phones).

Responsive

Below 768px the shop grid always shows labels-under (never the overlay). Also Worth Keeping switches its own name size at the same breakpoint (38px → 22px) and its grid drops from 3 to 2 columns, gap 12px → 8px. On (hover:none) the .held in-hand photograph never renders — only the still shows.

Do / Don't

Do
  • Keep every tile's photograph inside its own 4:5 frame so a zoomed image never spills onto a neighbour.
  • Let the studio set --x/--y/--z per piece in the lab rather than defaulting every piece to dead centre.
  • Use the overlay layout only where hover is reliable (desktop, mouse); fall back to labels-under everywhere else.
Don't
  • Don't round the corners of the desktop overlay tile — that radius belongs only to labels-under and related frames.
  • Don't call a piece a "product" in tile copy — it's a piece, or an artifact.
  • Don't show the in-hand photo on a touch device; there is no hover to reveal it cleanly.
