Price & Size Selector

The price line, then — on pieces that come in sizes — a single bordered control that opens into a grid of choices. Picking one closes it and locks the price row in place above the buy buttons.

Anatomy

.price sits above an optional .size block: a .size-toggle row (label, current value, chevron) that opens a .size-panel of a 5-column .size-list. Picking a size sets .picked on the block and bolds the value. Pressing Add to Bag with nothing picked opens the panel and adds .need, a red border that clears itself after 1.6s.

Live

Working control — click to open, pick a size, click outside or press Escape to close, or press Add to Bag with nothing chosen.

Responsive

No layout change below 768px — the size box and buy row keep the same structure; the surrounding .info column simply centres and narrows to the phone gutter.

Do / Don't

Do
  • Open the size panel and flag it red when Add to Bag is pressed with nothing picked — never block the click silently.
  • Bold the value only once a size is picked; the placeholder ("Select size") stays regular weight.
  • Close the panel on Escape or an outside click, same as any other disclosure control on the site.
Don't
  • Don't invent a size range — pull it from Shopify's variants for that piece.
  • Don't leave the "need" red border on permanently; it is a one-time nudge, not a validation state.
  • Don't shrink the buy buttons below 47px — that height is already 8px under the site's other black buttons.
