Type Hierarchy

Every serif and sans size the site actually sets, live at its real size and weight, with the token and the page it comes from. The site runs two families and never mixes them mid-word: Instrument Serif carries every title and name, Helvetica Neue carries everything else.

Anatomy

Serif titles are always uppercase, always weight 400 — the site never bolds Instrument Serif, it leans on size and spacing instead. The two exceptions are .step-name (Story page) and the home film's Henry .tagline, both lower-case italic. Sans weight 500 is reserved for a short list: the picked ring-size value, checkout/bag summary totals, the "Added to Bag" toast label, and the black email button.

Responsive

At 768px: h1 46→53px, h2 34→42px, wall heads 57.5→66.25px, eyebrow 15→16px, description 15→16px. At 1200px: h1 53→60px, wall heads 66.25→75px. Below 768px, tile names step down from the desktop hover-overlay size (38.83px) to the phone under-picture size (22px) because the layout itself changes from an overlay to a caption.

Do / Don't

Do
  • Set serif titles in uppercase, weight 400, at one of the sizes on this page.
  • Use the responsive token pair (phones → desktop) rather than a single fixed size.
  • Keep -.005em tracking on any new title-sized serif.
Don't
  • Bold Instrument Serif — the family has no bold cut in use anywhere on the site.
  • Invent a new near-duplicate size; check this page's oddity list first.
  • Set body copy below 13px or above 19px — nothing on the site does.
