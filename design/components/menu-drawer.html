Menu Drawer

The phone navigation: a white sheet that slides in from the left edge while the page underneath is pushed aside by the same distance, rather than being covered by an overlay.

Anatomy

  • Close — sits exactly where the Menu link was, top-left
  • Links — Shop, Custom, Shipping & Returns, Inspiration, Contact, About, Bag, one per line
  • The rest of the page — not hidden, pushed right by the drawer's own width

Responsive

The drawer only exists below 768px; at 768px and wider the desktop nav (Shop / Custom / About inline) takes over and the drawer force-closes if it happened to be open.

Do / Don't

Do
  • Push the page aside by the drawer's exact width, never overlay it
  • Let Close land exactly where Menu was tapped
  • Keep the rise-in stagger top to bottom
Don't
  • Add a background dimmer behind the pushed page — the site never uses one
  • Widen the drawer past 360px on large phones
  • Re-animate the links when arriving already open from another page (see below)

Notes

When a link inside the drawer points to another page, the new page loads with html.menu-arriving already set: the drawer starts open and instant (no slide, no rise-in — the .instant class kills both), and only then closes on its own once the new page has settled. This is what makes choosing "Shipping & Returns" from the drawer feel like the drawer stayed put while the page changed underneath it.
