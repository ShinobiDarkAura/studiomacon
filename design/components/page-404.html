404 Page

The whole site's "something went wrong" moment. It stays as calm and undramatic as any other page — a short line of copy and one way back, centred and settled with the footer close behind it rather than far below the fold.

Anatomy

  • Eyebrow — "Page Not Found"
  • Headline — "Lost Along the Way"
  • Lede — one calm sentence, no apology, no exclamation
  • CTA — "Back to the Shop", the one way out

Copy voice

Calm and third-person, never an apology and never an exclamation point. "This page has wandered off. The pieces are all still here." carries the miss lightly and points straight at the one thing to do next — the same restraint the rest of the site's copy keeps.

Responsive

The headline and body scale with the shared h1 rule (46px phones, 53px ≥768). Layout does not otherwise change — it is centred at every width, since the whole page is only ever this one short block plus the footer.

Do / Don't

Do
  • Keep the copy to one calm sentence
  • Always give exactly one way back — the Shop
  • Use body.fit so the footer sits close
Don't
  • Add a search box, sitemap, or a second link
  • Use humour, an apology, or an exclamation mark
  • Let the page run to full viewport height with the footer stranded far below
